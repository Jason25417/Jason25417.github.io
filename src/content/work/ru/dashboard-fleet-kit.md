## Что это

У каждого моего проекта в итоге появляется несколько небольших локальных панелей. Когда их стало достаточно много, запускать их, останавливать и находить превратилось в отдельную заботу. Dashboard Fleet Kit — фреймворк, который я из этого вынес: один файл-манифест, где зарегистрированы все панели, одна диспетчерская страница, которая их запускает, останавливает и проверяет их состояние, и микрофреймворк для написания новой панели.

Он использует только стандартную библиотеку Python. Без зависимостей, без шага сборки, без базы данных.

## Первая панель на его основе

Панель дерева issue появилась из моей проверки [hotaru](/ru/work/hotaru/). Она читает дерево issue прямо с GitHub, показывает, к каким issue прикреплены пул-реквесты, а к каким нет, и рисует карту зависимостей между крейтами.
