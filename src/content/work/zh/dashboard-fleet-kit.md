## 它是什么

我的每个项目最后都会长出几个本地小仪表盘。数量一多，启动、关闭和找到它们本身就成了一件麻烦事。Dashboard Fleet Kit 是我从这件麻烦事里抽出来的框架：一份登记所有仪表盘的清单文件，一个负责启停和健康检查的总控页面，再加一个用来写新仪表盘的微型框架。

它只用 Python 标准库。没有依赖，没有构建步骤，没有数据库。

## 建在它上面的第一个仪表盘

issue 树仪表盘来自我对 [hotaru](/zh/work/hotaru/) 的那次审计。它实时读取 GitHub 上的一棵 issue 树，标出哪些 issue 已经挂了 pull request、哪些还没有，并画出各个 crate 之间的依赖图。
