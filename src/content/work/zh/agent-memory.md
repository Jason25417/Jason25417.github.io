title: 给 AI agent 用的分层记忆
summary: 我为协作的 AI agent 维护的一套基于文件的记忆，在两台机器之间同步，另有一本记录「不靠 AI 我能做到什么」的账本。
---

## 问题

我每天都和 AI agent 一起工作，一台 Mac，一台 Windows。每次会话开始时，agent 都不记得上一次的事。把所有内容重新贴一遍是行不通的：记录在不断变长，而 agent 在会话开头能读进去的量是固定的。

## 分层

- **周记录。** 每台机器只写自己的原始记录，从不改对方的，所以两边永远不会冲突。
- **主题文件。** 每周把记录归并成一组主题，比如某个项目，或者我的某个习惯。主题文件是原地重写的，所以它越写越准，篇幅却不变长。
- **一页画像。** 一页稳定的偏好和事实，每个 agent 在会话开头都会读。它只能通过一份我批准过的修改提案来变更。

只有最底下一层允许无限增长。agent 必须读的部分，始终控制在固定的预算之内。

## 账本

和 AI 一起工作，很容易搞不清哪些事是我自己会做的。所以在记忆旁边，我还记了一本能力账本：每一条都是一件我声称「不靠 AI 也能做到」的具体的事，并附带检验办法。条目会被抽查。没通过的声明会被标成「已撤销」，并留在账本里。

这个仓库是私有的，因为它记录的是我自己的工作和习惯。
