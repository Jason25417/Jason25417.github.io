## できること

Scritto は音声を録音し、デバイス上でテキストにします。Whisper と Parakeet の音声モデルをローカルで動かしています。書き起こしと翻訳は同じタイムスタンプで揃えてあるので、翻訳の各行は元の文のすぐ隣に並びます。録音は検索できるライブラリに入り、iCloud で同期されます。アプリは七つの言語に対応しています。

## 信じる前に測る

Scritto に、声紋を使って別々の録音のあいだで同じ話者を見分けさせたいと考えました。そこで、機能を作る前にテスト用の実験台を作りました。声紋のしきい値を順に試して等価エラー率（EER）を求め、用語注入の実験を公開コーパス上の tcpWER で採点するものです。

結果は悪いものでした。録音をまたいだ話者の等価エラー率は 41.5% で、当てずっぽうに近い値です。数値に合わせて調整を続けることはせず、この測定結果をもってその方針をやめました。

同じ実験台で、もう一つ小さな疑問にも決着がつきました。Apple の API には、認識に独自の語彙を注入する仕組みがあります。コマンドラインで対照実験をしたところ、二種類ある書き起こしエンジンの片方でしか効かないことがわかりました。そのために標準のエンジンを切り替えると、得られる以上に精度を失います。
