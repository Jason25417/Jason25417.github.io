## 왜 플러그인인가

DeepSeek Harness는 제가 AI 에이전트를 돌리는 데스크톱 앱입니다. 플러그인 시스템이 있어서, 일상 작업에 무언가 빠져 있으면 먼저 본체가 이미 제공하는지 확인하고, 다음으로 누가 이미 만들었는지 확인하고, 둘 다 아니면 그때 직접 씁니다.

## 세 가지

- **dsh-composer-tweaks.** 입력창에 파일과 폴더 선택기를 넣고, Markdown 원문 보기와 렌더링 보기를 오갈 수 있게 하며, 제가 보낸 메시지도 Markdown으로 표시합니다.
- **dsh-external-bridge.** 로컬 HTTP 브리지입니다. 같은 기기의 다른 프로그램이 실제 세션을 열고, 프롬프트를 보내고, 답을 기다릴 수 있습니다.
- **dsh-session-auto-rename.** 세션 내용을 보고 자동으로 이름을 붙입니다. 최근에 나온 말일수록 더 무겁게 반영합니다. 세션 목록에 우클릭 메뉴도 추가합니다.
